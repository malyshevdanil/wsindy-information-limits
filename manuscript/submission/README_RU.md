# Submission package for Electronic Journal of Statistics

The main journal-formatted file is ../article_ejs.pdf, with source ../article_ejs.tex and the official, unmodified imsart.cls and imsart.sty. The class uses the EJS option. MSC codes: 62F12, 62M10 and 34A55. Author ORCID: 0009-0007-0947-3866. The file ../article_revised.docx contains editable Word equations.

The cover letter addresses EJS. The main contribution is the exact weak influence class and its nuisance-initial-state information reference. The heterogeneous-record theorem uses independent instruments and known covariance. Joint noise/span/record-count rates and consistent residual calibration of unknown covariance require further work. The common-trajectory GMM result and its small-sample bootstrap diagnostic are in the supplement.
