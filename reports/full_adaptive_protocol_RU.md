# Полное воспроизведение адаптивных авторских алгоритмов

Протокол `full-author-adaptive-v1`, зафиксирован до сравнительных результатов 11 октября 2026 года. Численные запуски выполняются в приватных ноутбуках Kaggle аккаунта `malyshevdanil`.

## Что именно воспроизводится

- **WSINDy:** полный `wsindy_ode_fun.m` из [MathBioCU/WSINDy_ODE](https://github.com/MathBioCU/WSINDy_ODE/tree/72d8d6e5be2b80bcfe5015dced399ace1ceca43f). Автоматический выбор ширины и степени тестовой функции по спектральному углу, адаптивное размещение по градиенту (`relax_AG=1`), автоматический SMAF, масштабирование библиотеки и выбор порога MSTLS по авторской функции потерь. Параметр размещения включён явно: в текущем демонстрационном скрипте он выключен (`relax_AG=0`). GLS оставлен в авторском режиме OLS (`useGLS=0`).
- **WENDy:** полный `wendy_fcn.m` и параметры `wendy_snf_params.m` из [MathBioCU/WENDy](https://github.com/MathBioCU/WENDy/tree/65c52a893b1f693cae3cd17e21854665ea814b9d). Оценка шума по данным, адаптивный минимальный радиус, четыре масштаба окон, ортогонализация и выбор размерности через SVD, полная ковариация с якобианом, IRLS до авторского критерия остановки и проверка нормальности. WENDy оценивает заранее заданную четырёхчленную структуру Ван-дер-Поля; качество обнаружения структуры для него не оценивается.
- **WmSINDy:** функции и основной цикл варианта Ван-дер-Поля из [CristianLopez85/WmSINDy](https://github.com/CristianLopez85/WmSINDy/tree/f1a781009a5c6adfd5650bec63ef30cc0673ae97/Fig7_Various_systems/VanderPol). Инициализация авторским WSINDy, совместное обучение коэффициентов и шумового сигнала, прямой и обратный RK4 прогноз, слабый остаток, обновление тестовых функций по очищенной траектории, необратимое отсечение и повторная регрессия. Сохранены 8 внешних циклов × 5000 шагов Adam, порог 0.15, шаг обучения 0.001, q=1, decay=0.9.

Исходники скачиваются по закреплённым коммитам и проверяются SHA256 из `configs/author_pins.json`. Основные функции алгоритмов не переписываются. Авторские исходники не включаются в распространяемый архив исследования; в нём остаются ссылки, хеши и наши адаптеры.

## Совместимость окружения

В Kaggle доступны Python 3.13, NumPy 2.1.3, SciPy 1.16.3, TensorFlow 2.20.0 и tf-keras 2.20.1. Для MATLAB-кода устанавливается GNU Octave 8.4.0 с пакетом statistics. Адаптеры расположены в `src/author_compat/`.

1. `build_Jac_sym.m`: точные аналитические производные заданной полиномиальной библиотеки вместо Symbolic Toolbox. Значения и порядок компонент сохранены.
2. `phi_weights.m`: точные значения и первая производная авторской bump-функции exp(-9/(1-x²)), та же нормировка и нулевые границы; применяется только к этому классу и проверяет вход.
3. `pagemtimes.m`: страничное матричное умножение для используемого двухаргументного вызова WENDy.
4. WmSINDy: legacy Adam, предварительное создание slot-переменных и повторная трассировка TensorFlow при обновлении окон. Последнее необходимо, чтобы граф использовал новые переменные контейнера после изменения ширины, а не сохранённые предыдущим графом окна. Формула потерь и 40 000 шагов сохранены.
5. Вспомогательная функция авторского Python WSINDy содержит ветвь со ссылкой на `tf` без импорта. В её namespace передаётся импорт TensorFlow; формулы не меняются.

Это воспроизведение авторских алгоритмов с явно указанными адаптерами, а не заявление о побитовой идентичности MATLAB и Octave или старой и новой версии TensorFlow.

## Контрольный авторский пример

Ван-дер-Поль с μ=0.5, начальным условием [-2,1], T=10, 1000 точками и независимым гауссовским шумом 25% от стандартного отклонения координаты, seed=1. Для WmSINDy используется полный бюджет обучения. Этот контроль подтверждает запуск конвейера; он не воспроизводит всю опубликованную Figure 7 с 50 повторениями.

## Замороженное парное сравнение

Ван-дер-Поль с μ=1, начальным условием [2,0], T=20. Два шага наблюдений h=0.04 и 0.01, два режима шума: физический OU с τ=0.3 и независимый гауссовский. Уровень шума 5% от стандартного отклонения чистой координаты на мелкой сетке. 16 независимых записей в каждой ячейке; seeds=910000,…,910015. Мелкая траектория и шум генерируются один раз и прореживаются, поэтому сетки вложены. Все алгоритмы получают побитово одинаковые наблюдения, что проверяется SHA256 входов.

Общая библиотека обнаружения: девять непостоянных мономов двух переменных степеней 1–3, как в авторском WmSINDy. Для честного парного сравнения фиксированные raw/Hermite MSTLS пересчитываются на этой же библиотеке; старые результаты с десятью членами автоматически не смешиваются с новым сравнением. Коррекция Hermite использует известную калибровочную дисперсию. Адаптивные авторские методы получают только наблюдения и время; WENDy дополнительно получает заранее заданную структуру модели. Истинные коэффициенты не поступают в оптимизаторы. Диагностический `true_vec` WENDy заменён единичным вектором, `use_true=0`.

Основные показатели: относительная ошибка коэффициентов, точное восстановление структуры для методов обнаружения, доля вычислительных сбоев. Сохраняются коэффициенты каждого запуска, выбранные окна, размеры базисов, итерации, оценки шума, история WmSINDy и время выполнения. Интервалы для долей — Wilson, для медиан и парных разностей — bootstrap по независимым записям; размер n=16 должен явно сопровождать таблицы. Сбой не удаляется из знаменателя успеха структуры. Полученные интервалы не обеспечивают точности исследования со 128 повторениями.

Использование CPU связано с занятыми двумя разрешёнными GPU-сессиями аккаунта Kaggle; чужие сессии не останавливаются. Сравнение времени MATLAB/Octave и Python/TensorFlow не используется для заявлений об относительной скорости алгоритмов.
