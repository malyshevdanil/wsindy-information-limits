# Редакция по критическим замечаниям

Целевой журнал из исходного плана: Applied Mathematics and Computation. Это ориентир подготовки, а не подтверждение принятия статьи или актуального квартиля JCR. Квартиль следует проверять по конкретному году, категории и базе перед подачей.

Новая серия `configs/revision.json` зафиксирована до выполнения. Старые пять Kaggle notebooks сохраняются как неизменные снимки. Новые seeds не пересекаются с прежними.

| Замечание | Выполненное изменение |
|---|---|
| Стандартные результаты поданы как новизна | Позиционирование переписано; классические инструменты атрибутированы. Новизна специализации не гарантирует достаточности для конкретного журнала |
| Предел лишь одной weak-оценки | Общая OU-теорема эквивалентности, двухточечная граница риска, Fisher information |
| Мало fixed-domain/EiV литературы | Включены Stein, Ying, Zhang, Fuller, Stefanski и более широкий weak-контекст; 19 DOI проверены, степень чтения отмечена отдельно |
| Неподтверждённая grid-диагностика | Убрана из abstract/contributions; сохранена как отрицательный результат в supplement |
| Слабый STLS | Свежая серия relative MSTLS, сверенного с авторским регрессионным блоком; oracle-support и Gaussian likelihood |
| Непроверенная ковариация коэффициентов | 2 000 paths на уровень, четыре уровня шума; joint coefficient covariance, singular-value guard |
| Неизвестен MC floor | Fourth-moment RMS floor и 250 affine-null bootstrap повторов на ковариационную ячейку |
| Нет ответа про h,T,M | Точная информация на сетке и непрерывном горизонте; сравнение длительности и независимых записей |
| Только одинаковые начальные условия | Завершён heterogeneous-IC эксперимент на 400 блоках; объяснены rank condition и ошибка усреднения sensor paths |
| Raw TeX в Word | Pandoc → native OMML; LaTeX → PDF |
| Графики/таблицы плохо читаются | Новые подписи, интервалы, раздельные метрики support/error, дискретные точки амплитуд |

Полные adaptive WSINDy/WENDy/WmSINDy пока не воспроизведены. Это отдельный пробел сравнительной части; запрещено обозначать регрессионный компонент как полное воспроизведение. Статья должна точно ограничивать сравнительные утверждения выполненными методами.

Новая серия завершена в `revision_fast` и `reweighting`. Итоги и границы готовности — в `q1_revision_results_RU.md`; таблицы и графики восстанавливаются скриптом анализа из сохранённых выходов. Исходная медленная серия использует те же seeds и не добавляет независимого подтверждения.
