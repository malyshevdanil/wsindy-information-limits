# Подтверждающая проверка: замороженный план

Дата: 13 октября 2026. Протокол: `endpoint_universal_paired_confirmation_v1`.

По явному указанию пользователя прежний абсолютный порог заменён
парными относительными критериями. Причина — на 32-путевом префиксе
этот порог не проходила даже likelihood-оценка с известным x₀.
Смена записана в `boundary_protocol_decision.json` до новых оценок.

Граничный holdout: 1968 путей, индексы 32…1999 исходной выборки,
четыре части по 492 пути. Они новые для граничного сравнения;
прежние benchmark-оценки уже архивированы. Генератор воспроизводит
наблюдения побитово; для каждой записи проверяется SHA256.

Ветки:

1. Три обновления с модельными сопряжёнными тестами и initial-контролями.
   Это реализация score-направлений в первом порядке. Критерий —
   RMSE / RMSE likelihood ≤ 1.05.
2. Главная ветка: прежние 480 bump-окон, 12 полуокон, ненулевых на
   концах, и два момента Y(0)-u. Окна строятся только по времени.
   Критерий — закрыть ≥50% RMSE-разрыва прежней weak с likelihood
   на одной и той же holdout-выборке.
3. Прежняя boundary-free weak и известная начальная likelihood:
   архивные результаты, сравниваемые после проверки наблюдений.

Используется точная дискретная эрмитова ковариация с граничными
кросс-термами. Универсальная ветка использует тот же модельный пилот
ковариации, что прежняя weak. ОДУ не требуется для построения окон;
весовая часть всё ещё интегрирует пилотную модель. Ускорение заранее
не заявляется: отчёт сравнит фактическое время.

Основное решение — по замороженным точечным критериям; отдельно
5000 парных bootstrap-повторений дают интервалы Monte Carlo.
Неположительный исходный разрыв делает критерий доли неоцениваемым.
Отрицательный результат ограничивается этим конечным семейством.

Второй протокол: `vdp_added_cubic_local_information_and_author_wsindy_v1`.
Нулевая модель — исходный Van der Pol. К ней добавляется δx³ в v′;
отрицательное направление сохраняет возвращающую силу и ограниченность
орбит. Ковариация шума фиксирована по исходной модели.

Ориентиры вычисляются через дополнение Шура по остальным коэффициентам
полиномиальной библиотеки авторского WSINDy, а для weak — дополнительно
по двум начальным координатам. Отдельно выводится узкая модель core5.
Проверяются устойчивость к SVD-порогу и уточнение сетки информации.

Полный закреплённый авторский WSINDy: 100 путей на каждом из пяти δ
при двух уровнях шума, 0.5% и 5%. Сетка заранее задана множителями
[0, -0.5, -1, -2, -4] локального weak-порога. Используются адаптивные
авторские окна, сглаживание и MSTLS, без подбора порога по эксперименту.
Всего 1000 подгонок. Будут выведены частоты включения, Wilson-интервалы
и ложное включение при δ=0. Локальный гауссовский ориентир не является
точной гарантией восстановления носителя при конечном δ.

Старые вычислительные очереди остаются отключены. Все новые задания
имеют отдельные замороженные notebooks. Релиз и подача пока не выполнены.
